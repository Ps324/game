# The Outlaw of Attention

**Steal Back Your Time**

A short, top-down retro pixel-art story game about attention, infinite scroll, unpredictable rewards, personalisation, and deliberate technology use.

Play as **Robin Focus**, an outlaw fighting Tech Lords who harvest the kingdom's most valuable resource: human attention.

## Play

Open `index.html` in a current browser, or enable GitHub Pages for this repository. No build step or external dependencies are required.

## Controls

- **WASD / Arrow keys** — move
- **E / Enter / Space** — interact / advance dialogue
- **Arrow keys** — choose dialogue options
- **M** — mute / unmute

## What the game explores

1. Infinite scroll removes natural stopping cues.
2. Unpredictable rewards encourage another swipe.
3. Personalisation learns what keeps each individual engaged.
4. Excessive scrolling often matters because of what it displaces: sleep, focused work, hobbies, relationships, and deliberate choice.

The game deliberately avoids a simplistic “phones are bad” message. Technology can be useful and entertaining; the focus is on design incentives, user control, and deliberate use.

## GitHub Pages

The included workflow deploys the static game from `main`. In **Settings → Pages**, choose **GitHub Actions** as the source if GitHub asks.

## Tech

- HTML5 Canvas
- Vanilla JavaScript
- CSS
- Web Audio API
- No external libraries
- No analytics

The game source is stored as a small gzip/base64 browser bundle split across three files so it can be deployed as a completely static site.

Typical play time: **12–16 minutes**.
